# Abin Muhammed KK — Portfolio

A responsive personal portfolio for a B.Tech student exploring Data Science and AI. The site is built with plain HTML and CSS and can be hosted as a static website.

## View locally

Open `index.html` in a modern web browser. No installation, server, or build step is needed. An internet connection loads the optional Google Fonts; system fonts are used if they are unavailable.

## Files

- `index.html` — page content, navigation, contact enquiry form, and lightweight interactions.
- `styles.css` — layout, colors, animation, and responsive styling.
- `student-at-desk.png` — character illustration displayed in the portfolio.

## Contact form

The form is hidden until a visitor selects **Contact me**. Submitting it opens a draft in the visitor’s email app addressed to `abinmuhammedwork@gmail.com`; the website itself does not send or store form submissions.

## Publish with GitHub Pages

Create a public repository, upload these portfolio files to its root, then enable GitHub Pages from the repository’s **Settings → Pages**. Select the `main` branch and `/ (root)` as the source. GitHub will provide the public website address after deployment.

## Privacy and security

This is a static site and does not contain a backend, analytics, cookies, passwords, API keys, or stored form submissions. The contact email and character image are public because they appear in the site. The page loads optional fonts from Google Fonts when internet access is available.
